# InGame

A mobile-first (iOS + Android) app where gamers build a personalized, beautifully-customizable
collection of the games they play — a retro arcade-styled "trophy case" — and share it with friends.

InGame is the v2 of an earlier prototype (GameStatsApp). It is a **greenfield build**: it reuses
none of the prototype's code, carrying forward only the lessons learned and the retro arcade
*aesthetic DNA* as design reference.
