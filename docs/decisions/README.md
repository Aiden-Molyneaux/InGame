# Decisions (ADR-lite)

This folder records **why** we chose what we chose. A decision record is the resting place for a
resolved `open-questions.md` item (see the change protocol in [`../00-INDEX.md`](../00-INDEX.md) §4).

## Format
Going forward, **one decision per file**, named `NNNN-short-title.md`:

```
# NNNN — Title
- **Date:** YYYY-MM-DD
- **Status:** accepted | superseded by NNNN
- **Related IDs:** CARD-12, ECON-03 …

## Context
What prompted the decision.

## Decision
What we chose.

## Rationale / alternatives
Why; what we rejected and why.
```

Foundational decisions made during the initial brainstorming are consolidated in
[`0001-foundational-product-decisions.md`](0001-foundational-product-decisions.md). Future
decisions get their own files.
