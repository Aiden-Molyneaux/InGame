# Design

This folder holds the UI/UX layer of the project. Two documents will live here:

1. **`ui-design-requirements.md`** — *next deliverable.* Authored by Claude Code from the
   product-spec: for each screen/surface, what the user must be able to do, expressed against
   stable feature IDs (e.g. COL-06, CARD-01). This is the brief handed to **Claude Design**.

2. **`design-spec.md`** — produced by Claude Design and committed back here: the actual screens,
   flows, components, and visuals. It owns the truth for *how the app looks and is touched*
   (see truth-precedence in [`../00-INDEX.md`](../00-INDEX.md) §2).

Until then, this folder is intentionally empty. Behavior questions raised during design go into
[`../open-questions.md`](../open-questions.md), not into the spec directly.
