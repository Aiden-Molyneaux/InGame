Foundation Rules
F-01 Never crop a Game Card. Full face, scaled — never cropped or slivered.
F-02 The step belongs to the card. TL+BR pixel-step = GameCard signature; chrome is square. A button may borrow it at half scale, and colour signals intent: gold+step = an acquisitive action — creates a card (ADD), moves PIXELS (currency / PriceChip / BuyBar, ECON-01), or a primary add-to-collection; system-orange+step = a prominent non-acquisitive action (RETRY, ADD FRIEND, SHARE). (OQ-036; gold-economy ratified 2026-06-23)
F-03 Keycap physics on both surfaces. Solid keys with a hard drop edge — 4px shell, 3px screen actions, 2px tools — that travel when pressed. (OQ-006)
F-04 Nav legibility beats customization. Stickers/colours never obscure the 5 keycaps.
F-05 Pips are lights, not chrome. Always round, in every corner system.
F-06 4-step type scale (21/15/11/9) on screen. Card plates are print and scale with the card.
F-07 Radius lives on plastic. Rounding only on the shell; on-screen chrome is 90°.
F-08 One font per surface. Chakra Petch on the screen; Paytone One on the plastic. No third voice.
F-09 No sunken containers. Surfaces are flat planes one step lighter than their background; selection = an accent border + the StateMark (the orange pixel-square, screen accent — not the pink shell LED), never an inset recess, and never a one-sided left-edge accent rail (a left-border accent stripe on a row, callout, or toast) — mark a highlighted row with a flat accent-tint fill (plus accent text), and selection with a full accent border + the StateMark. Named exceptions: pressed keycaps (F-03's travel) + text inputs.
