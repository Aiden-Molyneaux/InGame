Add Game · Draft B — One Surface, Progressive Disclosure (C5 v2)

Eight moments of the Add Game flow (design-req 4.1) on one anchored screen — no page transitions. The SearchField is permanent at the top; results, the add form, and the card step all expand inline beneath the chosen game in an accordion rhythm (FlowTakeover — the FlowHeader carries no step dots; your place lives in the disclosure state itself). Optimized for fast repeat adds: a completed add collapses to a confirmation strip, the field clears + refocuses. New named components staged here: FlowTakeover · FlowHeader · TextField · SelectField · OptionSheet (inline chip-row form) · ResultRow · InlineBanner · CardPicker. Standalone file — sample art = built-in SVG symbols. Lifecycle & offline panels (P9–P10: skeleton · load-error + RETRY · offline writes-gate) are deferred to the converged artboard per the stage-1 draft contract.
