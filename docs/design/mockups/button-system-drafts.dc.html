Three button languages for the in-app screens, shown on the Midnight theme. Each covers the full vocabulary — primary / secondary / destructive actions, tool chips (search, sort, filter, view), tertiary links — plus the Collection tools bar rebuilt in that language. ADD keeps its 2/4 TL+BR card-step in every take.

The shell's key language, on screen. Buttons are plastic keycaps: solid fill, hard 3px drop edge, top highlight; pressing travels down. Hierarchy by plastic color — accent / cream / alert red. Active tools stay pressed-in with a lit pip. Loudest physicality, very InGame.

Buttons as card print. Borrows the GameCard title-plate: Silkscreen pixel type, flat ink, hard offset shadow like a sticker lifted off the card. DELETE wears the hazard tape from the Resident Evil plate. Pressing flattens the sticker to the surface. Most collectible-feeling; labels must stay short.
