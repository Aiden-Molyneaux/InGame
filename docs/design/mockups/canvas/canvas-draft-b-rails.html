Canvas — Draft B “Cockpit rails” (Card editor · breakout posture)

The PARTIAL breakout proposal for OQ-007: the shell opens and slides away, but the bezel stays — a thin workbench frame, so the editor still lives inside the device (the metaphor bends, never breaks). Inside it: zero modality (the Styler-cockpit lineage) — a persistent left tool rail (icon keycaps: ADD · LAYERS · COLOR · the 👁 preview hold), a persistent bottom tray whose contents swap with the active tool/selection, and the canvas between them. Nothing floats, nothing summons; one tap re-aims the tray. The LayerRack is a horizontal filmstrip of layer thumbnails in the tray — structure you scrub, not a list you manage. Same contract: composition in from the Styler, publish here, cap 30 (OQ-008). Lifecycle deferred to converge.
