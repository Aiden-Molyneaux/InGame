Collection — sort/filter drawer (one home for every tool)

One pulled-up drawer hosts all of COL-07/09: scoped search (title · developer · publisher), the three views (shelf / compact grid / dense list), sorts with the tap-again ASC/DESC flip, and status + genre filters. DONE commits, RESET clears.

OQ-034 proposal — keycaps act, the drawer configures. Tap = the tool's one-bit action: search → in-place field, live-filtering the current view · sort → flip ↑/↓ (the drawer's tap-again rule, promoted to the bar) · view → cycle the three modes. FILTER is multi-choice, so its tap is the drawer's always-visible doorway; long-press any keycap = this drawer, opened at that tool's section. Chips wear their state (pressed + pip), the count keycap narrows to 12 OF 48, and in-place search + this field are one query state — dismissing the keyboard keeps the filter; ⊗ clears it.

OQ-031 proposal: manual order is a sort choice ("MY ORDER"), not a separate mode to get lost in — selecting it unlocks ARRANGE (long-press a card & drag), and the tools-bar grip is its shortcut.

Collection — in-place search (OQ-034 — the bar becomes the field)

Tap the search keycap and the tools bar morphs in place — no drawer, no separate screen; the query live-filters the current view (list mode shown) and the count keycap narrows to 2 OF 48. COL-09's scope made visible: BUN hits Destiny + Marathon through their developer, so each row wears a small match tag (matched letters bright) and a result never looks random. The Now-Playing hero yields while a query is active. Keyboard SEARCH dismisses and keeps the filter (the search keycap returns pressed + pip); ⊗ clears and restores.

OQ-035 — the keyboard is the one object we don't own: the OS keyboard buries the nav band and slices the handheld illusion while typing. Baseline: system keyboard, keyboardAppearance matched to the screen theme, focused field riding directly above it. The tempting alternative — an in-app keyboard skinned as cream device keycaps — is maximum metaphor but costs autocorrect / swipe / dictation / i18n; flagged for a deliberate call before the Card editor (the heaviest text surface).

View modes (COL-07) one dataset, three presentations — the Now-Playing hero persists in all three; only the library rendering below it changes. The tools-bar view keycap always wears the current mode's icon — tap cycles shelf → grid → list (OQ-034); non-default modes press it + light the pip.

Shelf (the showcase — flip through your binder)

Every entry gets the hero treatment — the Now-Playing hero component reused row-by-row (reuse mandate): full card at hero size, stat eyebrow (HRS · STATUS, soft — accent stays the hero's), title, and a dim catalog line (developer · year · genre). LOG HOURS stays hero-exclusive, so the pinned game reads senior even when every row is hero-shaped; the ▶ NOW tag marks its place in the flow (same precedent as grid).

Spec ripple (OQ-033): shelf rows showing hours/status updates decision 0012's "list is the only stats mode" rationale — the list's job becomes density (scan ~8 rows vs ~2 here). One-line design-req §3.1 edit if adopted.

Grid (dense browsing — the h2-underlay layout, now named)

The populated view we've been drawing all along is grid mode: 2-wide full card faces, never cropped (OQ-014), no added label chrome (0012) — the title plate is baked into the card's flattened image (CARD-01/15). The ▶ NOW tag carries pin context; tap any card → Game page.

Density ladder: ~2 games/screen (shelf) → ~4 (grid) → ~8 (list) — each mode owns a distinct rung. The view keycap shows the 4-square glyph, pressed + lit (non-default mode).

List (management — the Completionist's scan)

Now-Playing unset (has games, no pin — §3.1)

The hero never goes blank. With games but no pin, the hero slot becomes an inviting nudge (§1.7): a ghost card + SET NOW PLAYING (a plain action button — not gold+step; pinning doesn't create a card, F-02). The library still fills the grid below.

Distinct from the first-run empty (zero games → the ADD ghost): here you have a shelf, you just haven't chosen its face. No card wears the ▶ NOW tag until you pick (WTP-03).

Offline — a friend you can't reach (calm, not Signal Lost)
