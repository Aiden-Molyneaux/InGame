On-screen state marker — replacing the pink pip

The pink pip (--accent #ff3d77, round + glowing) is the shell's LED language — it belongs on the plastic (the NavBand LED, the power light). It has leaked onto the flat screen as the active/selection marker in three on-screen roles. These drafts swap it for an on-screen-native marker (--scr-accent #ff9f43 orange, flat, square) — which is what F-09 already asks for. The shell LEDs stay pink and untouched.

F-05 — Pips are lights, not chrome. Round LEDs, on the plastic.
F-07 — Radius lives on plastic. On-screen chrome is square (C5).
F-09 — selection = an accent border + pip (the screen accent, not pink). The boards kept it pink; these honour the rule as written.
