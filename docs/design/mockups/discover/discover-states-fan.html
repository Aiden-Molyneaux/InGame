Discover States — Card-fan variant (Two rooms · the Add Game CardFan aesthetic)

A sibling of `discover-states.html` — the converged Two-rooms board kept verbatim (standard `ScreenHead`, the smaller bottom-docked `SegmentedKeycap`, real games, the three Discover sections, lifecycle) — but every game is now shown as the Add Game `CardFan`: a swipeable 3-up fan with the forefront full-face, both neighbours genuinely visible (zero plate occlusion), the meta above and dots / SWIPE / position below. The fan replaces the rails, rows and grids across Up Next (the playlist), Upcoming, Friend recs, Trending, and Search.

Renders in-frame (DeviceShell + NavBand persist, DISCOVER keycap active). No PIXELS mark (non-commerce). Full matrix incl. lifecycle (Skeleton · “Signal Lost”+RETRY · Offline writes-gated, SYS-10). Real titles; values illustrative (OQ-002/011). Pairs with the row-based `discover-states.html` for the owner to pick the aesthetic.
