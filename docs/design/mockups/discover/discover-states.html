Discover States — Converged Board (Two rooms · bottom toggle · real games)

The converged §3.2 per the owner gate ruling (2026-06-13): Draft A “Two rooms” — the UP NEXT ↔ DISCOVER toggle is a hard binary. The seven ruled changes are baked in: (1) the `SegmentedKeycap` moves to a smaller bottom-docked footer (above the plastic NavBand); (2) a standard `ScreenHead` names the active page; (3) the sample roster is real games; (4) Browse-By removed (DISC-02 parked → OQ-057); (5) Discover is three sections — Upcoming (browse + add + notify) · Friend recommendations · Trending; (6) games-only search kept as a header action (DISC-03); (7) Up Next is the Now-Playing pin + queue + a primary ADD FROM COLLECTION.

Renders in-frame (DeviceShell + NavBand persist, DISCOVER keycap active). No PIXELS mark — Discover is non-commerce (trending shows adoption counts, not prices). Full matrix incl. lifecycle: Skeleton · “Signal Lost”+RETRY · Offline (browse-from-cache, writes gated, SYS-10). Real titles; values illustrative (OQ-002/011). P10 — Offline (writes gated, SYS-10)

Offline is its own calm pattern (never the error alarm): the OfflineStrip + last-synced Upcoming and Trending stay browseable from cache, while the writes are gated — NOTIFY-ME and ADD-TO-QUEUE dim until the connection returns, then it auto-recovers.
