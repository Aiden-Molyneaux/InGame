Find / Add Friends — 4.8 states board (built off Friends draft A)

The screen that populates the social graph — the destination of the Friends tab’s find/add hooks (§3.3 → the ADD FRIENDS header key). One coherent build, not a 3-direction exploration: it inherits Friends draft A verbatim — the DeviceShell + NavBand (FRIENDS active), the tokens, the flat Inset-Recess keycaps, the orange StateMark, the F-06 type scale (21/15/11/9), and the §1.8 lifecycle grammar — so 4.8 reads as the same app.

The crux is the relationship-state machine: every person surface shows one state → the single right action — NOT-CONNECTED→ADD · SENT→CANCEL · INCOMING→ACCEPT/DECLINE (silent) · FRIENDS→open profile · COOLDOWN→disabled+reason (SOC-08) · BLOCKED→limited (SOC-09). New components: PersonRow, the bottom-docked SearchField (OQ-035), QrCard, InviteLanding/SenderSummary (SOC-10). Reused from A: RequestRow, InviteHook, the avatar, the §1.6 lifecycle family.

Non-commerce — no gold (adding a friend creates no card, F-02), no friend SHARE (OQ-052 cut), no contacts-matching (SOC-07); Block is a relationship state here, its LIST lives in Settings (4.15). Cast: Maverick=self · Riko/Vanta=friends · Nova/Sable=incoming · Hexandra=sent · strangers @pixeljune/@riptide/@hollowmatt… across the states. Counts illustrative. Shape gaps → OQ-072 (/users/search) · OQ-073 (/invites/:token + QR). Flat buttons = Scanline Energize (rippled to the locked F-03 affordance, 2026-06-18).
