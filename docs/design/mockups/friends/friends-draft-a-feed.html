P1 — feed landing (the model thesis)

The feed IS the screen. You land in the SOC-06 stream — aggregated rows (“Riko added 12 games” as one capped item, +9 peek), beat/publish events, trivia excluded. The roster is a slim ONLINE NOW rail (→ ALL FRIENDS); requests are an inline banner; find/add is the header key. No sub-tabs — one scroll.

Best for: an active social graph. Weakest for: the cold-start/0-friend reality — an empty feed is a dead landing (see P5 / Draft C).

P2 — the activity feed (SOC-06 · active)

All five aggregated types: added_games (capped + peek), beat_game, published_card (foil peek), unlocked_achievement (a notable one — the badge tile, no card), completed_game. FeedRow = avatar + actor + actor+type predicate + a capped object peek + relative time.

Quiet variant (not pictured): when the window is thin, the feed collapses to a 1–2 item digest + a gentle nudge — “It’s quiet. Add more friends to liven things up →” (Draft C makes that the default). Feed-item shape unspecified → OQ-071.

P5 — cold-start (SOC-07/10)
