Game page — Draft B “Tabbed dossier” (4.2 · the adaptive hub)

The same dense page — a shared catalog page + your owned state + a friend-view + the gallery + the switcher — but chunked into three tabs by a seated section switcher worn under the head: PLAY (your card + stats + edit) · CARDS (the switcher + community gallery + design-new) · ABOUT (canonical facts + presence + friends-who-own + suggest-edit/report). The conventional-legible pole — each screen does one job; nothing competes for the same scroll. The page adapts by setting the default tab: neutral → ABOUT (PLAY locked until you own it) · owned → PLAY · friend-view → PLAY (their card). The tab row aligns with the forthcoming `SegmentedKeycap` (flagged, not depended on — OQ-057-adjacent). Card-flip (P3), atomic adopt (P5/P6), the OQ-056 switcher (P4) all live inside their tab. Lifecycle (soft-hidden · loading · offline) deferred to converge. Sample: Destiny, 210 hrs; Maverick = you · Riko/Vanta = friends. Numbers illustrative (OQ-002/011).
