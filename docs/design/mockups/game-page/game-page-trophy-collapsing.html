Game page — Take A “Collapsing Trophy” · high-fidelity

The chosen direction, built properly: the equipped card is a trophy that opens large and alive, then collapses into a sticky header as you scroll so it's always present but never blocks the depth. Every §4.2 field has a home; every design convention enforced — F-01 (cards never cropped or overlaid), F-02 (gold+step = card-creating only; everything else is the orange `KeycapButton`), F-06 type scale, F-07/C5 square chrome + the card step, F-09 (flat planes; selection = accent border + pink pip), `shadow.key` on every keycap. Owner notes applied: the “your card” tag removed; the full owned field set incl. platforms + date acquired; Your Cards larger + unobstructed (state reads below the card, the main one carries the F-09 selection) with a hold → options drawer (set main · edit · delete …); and Community = a single link when you own it, a listed gallery when you don't. Sample: Destiny, 210 hrs; Maverick = you · Riko/Vanta = friends. Numbers illustrative (OQ-002/011). Rating PENDING (OQ-058) · delete semantics (OQ-061).
