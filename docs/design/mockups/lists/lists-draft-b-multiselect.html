A two-beat PICK → ARRANGE flow. Reached from the Profile (PROF-05). Non-commerce → no gold (F-02). Counts illustrative.

S3a · Full (5) — the 6th is refused

At 5 / 5 the cap is hit (the §6 capped list): every un-picked card dims + locks, a 6th tap is refused with the orange CAP REACHED note (deselect-to-free). Picked cards stay tappable to deselect. No gold anywhere — the cap warning wears system orange.

S3b · Arrange — the second beat (drag the strip)

Phase 2: the chosen five become a horizontal podium strip (#1 raised) — drag to re-order (the COL-07 ARRANGE gesture → PATCH /me/lists/:id { orderedGameIds[] }), with the ranked roster beneath. #1 wears orange (not gold). BACK returns to PICK; SAVE writes the list — the model's distinct two-phase split.
