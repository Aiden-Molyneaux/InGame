InGame · Onboarding (4.14) — States

FIRST-PASS · FOR OWNER REVIEW · NOT YET CONVERGED

The defining constraint: never land a new user on an empty Collection. Onboarding is a light, fully-skippable guided seed that ends by depositing the user onto a populated Collection — built from the same C5 grid the Collection board already draws. Grammar matched to Add Game (FlowTakeover · FlowHeader · bottom-docked SearchField · CardFan) and Collection (the populated landing) and Discover (the rail idiom).

IDs: AUTH-06 (guided quick-start) · NOTIF-04 (push pre-prompt, both branches) · CAT-09 (the "popular" most-collected rail seeding the adds) · COL-01/COL-02 (add + status). Gold only where a step literally creates a card (the ADD & DESIGN teaser, F-02) — plain game-adds are orange/cream.

The guided quick-start (AUTH-06) A bounded, skippable FlowTakeover — the NavBand stays (F-04). The whole job is to fill the shelf before the user ever sees it.

O8 — NOT NOW (the soft decline — the OS one-shot is NOT spent)

The correctness state. NOT NOW on the pre-prompt lands the populated Collection directly — the OS prompt is never fired, so the precious one-shot stays unspent (NOTIF-04). A calm orange (never alarm-red) banner notes "we'll ask again at a good moment" (re-offer cadence, SYS-04) and points to Settings. The shelf is populated either way: onboarding's constraint holds on every branch.

The payoff — land on the real Collection The reward IS the shelf. The finale is the genuine Collection home (verbatim C5 grid + Now-Playing hero + the full browse/tools bar). If the user added games it's populated; if they skipped every add (owner ruling) they land on a friendly empty that pushes them to add — never a dead grid, never a machine-seed.

O10 — Zero-add fallback (a friendly empty that pushes to add — no auto-seed)

If the user skipped every add, they land on the Collection board's inviting empty verbatim — the dashed ghost-card doorway (solid would read as loading), a warm headline, the gold ADD GAMES keycap routing straight back into the add step / catalog (4.1), and the POPULAR FIRST ADDS row + BE-THE-FIRST hook to make the next tap effortless. Owner ruling (resolves OQ-B): no SURPRISE ME, no auto-seed — a skip-everything user lands on an empty-but-friendly Collection that gently pushes them to add, never a machine-seeded shelf. It's a doorway, not a dead end (design-req §1.7).
