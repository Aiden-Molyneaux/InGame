Settings (§4.15) — CONVERGED board · C-triage feedback · notifications as its own page

Gate ruling (2026-06-14): "use feedback draft C triage and make the notifications feature its own page, similar to triage." Applied: the feedback surface is Draft C "type-first triage" (drafts A/B retired), and NOTIFICATIONS becomes a `ListRow` that opens its own dedicated page — so Settings settles into one grammar: a lean list of rows where each heavier feature (notifications · blocked · feedback) opens a focused page. Composed from the §1.5 catalog; introduces the flagged `Toggle` · `ConfirmDialog` · `LogAttach` · `FeedbackConfirm` (+ C's `TriageCard`). Non-commerce — no PIXELS, no CountKeycap; PROFILE keycap stays active throughout.

State matrix — the converged board

The list: loaded (one scroll, S1+S2) · unverified-email (AUTH-08) · loading `Skeleton` · offline writes-gated (SYS-10) · load error "Signal Lost"+RETRY (§1.8). ✓

Feature sub-pages (row → its own page): NOTIFICATIONS (NOTIF-02, grouped toggles) + its OS-permission-declined recovery (NOTIF-04) · BLOCKED USERS list + unblock (SOC-09) · DELETE ACCOUNT `ConfirmDialog` (AUTH-07). ✓

Feedback (SYS-11 · C triage): the triage chooser · the minimal feedback form (no-tax) · the bug form (diagnostic chips + the `LogAttach` hero, OQ-060 room) · submitting · `FeedbackConfirm` · error `Toast`. ✓

Residual (presentation, for design-spec formalization): the feedback SUBMIT colour (drawn red `/destructive`; `/primary` alternative open) · the `ConfirmDialog` spatial form (drawn centered modal; bottom-`drawer` alternative open).
