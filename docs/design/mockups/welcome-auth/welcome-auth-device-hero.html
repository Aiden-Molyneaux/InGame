W11 — offline (writes gated · SYS-10)

Offline ≠ error (SYS-10). Auth is inherently a write (it can't read from cache), so the calm `OfflineStrip` rides under the header (one offline language app-wide; no red, auto-recovers) and every CTA gates — SIGN IN, the Apple button, and FORGOT PASSWORD all dim. Typed values are kept; a plain line promises it resumes on reconnect. The only red on this board is W4's field errors and W5's auth-fail.
