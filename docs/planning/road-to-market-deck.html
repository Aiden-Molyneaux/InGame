§3 · FOUNDATIONStack verdict & recurring cost

Verdict: keep the stack

Expo/RN · RTK Query · Express/TS · Drizzle/Postgres · zod · RevenueCat — boring on purpose, right for a solo hands-off build.

  • Monorepo: apps/mobile · apps/api · packages/shared (zod = executable api-contract)
  • SYS-01 scoping helper + SYS-07 authz test per endpoint
  • ACH-08 event bus in Foundation → feeds achievements + analytics
  • Migrations reviewed in PR; destructive = owner gate
  • Backups auto-daily + one tested restore drill before users

Recurring ≈ $25–50/mo

Apple Dev$99/yr
Google Play$25 once
Postgres + API host~$14–25/mo
Object storage/CDN~$0–5/mo
Sentry · PostHog · RevenueCat · EAS · CI$0 (free tiers)

Token spend (Q1) is heaviest M4–M7 + a steady trickle from per-PR reviews and per-phase audits.

§5 · THE SPINEHands-off guardrails (enforced, not advisory)

Enforced merge gate

Branch protection on main · required green CI + review · per-PR: typecheck→lint→unit→integration + secret-scan + SCA. E2E nightly.

3 owner-approval change-classes

  • Destructive migration
  • Auth / SYS-01
  • Economy / IAP / ledger

Everything else = agent review + green CI.

Agent review is BLIND to…

authz under concurrency · economy race/double-spend · real IAP/refund · spec-intent drift · aesthetics. → the manual gates cover exactly these.

Definition-of-Done per task: spec-ID · risk-domain tests · SYS-07 authz test if mutating · zod input · no unjustified new dependency.
